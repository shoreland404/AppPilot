# Contributor Covenant Code of Conduct

## Our pledge

We as members, contributors, and maintainers pledge to make participation in AppPilot a harassment-free experience for everyone.

## Our standards

Examples of acceptable behavior include:

- respectful communication,
- constructive feedback,
- inclusive collaboration,
- willingness to help others understand Linux packaging and desktop application constraints.

Examples of unacceptable behavior include:

- harassment,
- personal attacks,
- trolling,
- other conduct that would reasonably be considered inappropriate in a professional community.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, and other contributions that do not align with this code of conduct.

## Scope

This code of conduct applies within project spaces and in public spaces when an individual is representing the project.
